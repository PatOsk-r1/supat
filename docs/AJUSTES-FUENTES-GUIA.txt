CÓMO FUNCIONA (resumen)
----------------------------------------------------------------------
- Supat tiene dos fuentes, "Fuente A" y "Fuente B". Cada una tiene su tarjeta en Ajustes → Fuentes de contenido, con las mismas secciones.
- Un servidor importa el catálogo de la API y lo guarda en la base de Supat. El navegador nunca habla con la API del catálogo.
- El video lo reproduce el navegador directo desde la URL que se obtenga, así que esa URL tiene que funcionar SIN encabezados, SIN cookies y SIN credenciales dentro.
- Las respuestas de la API tienen que ser JSON.

CÓMO SE ESCRIBEN LAS RUTAS DENTRO DEL JSON (campos que dicen "Ruta ...", "map.*", "epmap.*")
- Campo simple: title
- Campo anidado: info.title
- Primer elemento de una lista: images[0].url
- Todos los elementos de una lista (por ejemplo géneros): genres[].name
- Alternativas (si falta la primera, usa la segunda): title|name
- En el mapeo, las rutas son relativas a CADA resultado de la lista, no a la respuesta completa.
- "Ruta del array de resultados" es la ruta, desde la respuesta completa, hasta la lista. Vacío significa que la respuesta ya es la lista.

VARIABLES QUE SE PUEDEN USAR EN RUTAS, PARÁMETROS Y PLANTILLAS
- {id}: id del título (en los endpoints de temporadas y episodios, es el id de la SERIE).
- {seriesId}: id de la serie (en las plantillas de reproducción de episodios).
- {season}: número de temporada.
- {episode}: número de episodio.
- {tmdb}: id de TMDb.
- {imdb}: id de IMDb.
- {lang}: valor del campo "Idioma: valor".
- {data.campo}: cualquier campo guardado con "Otros campos". Por ejemplo, con slug=info.slug se usa {data.slug}.

FORMATO DE LOS CAMPOS DE VARIAS LÍNEAS ("nombre=valor")
  Una por línea, por ejemplo:
  language=es
  sort=updated

QUÉ NO ES COMPATIBLE CON LA REPRODUCCIÓN (no se puede resolver con ajustes)
- La credencial tiene que ir dentro de la URL del video que abre el navegador.
- El servidor de video exige encabezados (por ejemplo Authorization) o cookies.
- El video no permite CORS (para HLS, el navegador tiene que poder leerlo).
- DRM (Widevine, FairPlay, PlayReady).

======================================================================
OTRA PANTALLA: PRIORIDAD DE DATOS (Ajustes, debajo de las fuentes)
======================================================================
Si un mismo título está en las dos fuentes (se une por TMDb o IMDb, nunca por el nombre), acá se elige qué fuente manda en cada dato. Si la fuente elegida no tiene ese dato, se usa la otra. Un dato vacío nunca borra uno existente.
Campos: Título · Título original · Sinopsis · Póster · Imagen de fondo · Géneros · Año · Fecha de estreno · Puntaje · Título del episodio · Sinopsis del episodio · Imagen del episodio · Duración del episodio.
Cada uno ofrece "Fuente A primero" o "Fuente B primero".
- "Guardar prioridades (sin aplicar)" guarda la elección pero todavía no cambia datos.
- "Vista previa" muestra qué cambiaría.
- "Aplicar a todo el catálogo" pide confirmación y lo aplica por tandas ("Continuar" sigue si queda a medias).

======================================================================
BOTONES DE CADA TARJETA DE FUENTE (en este orden)
======================================================================
1. Guardar configuración: valida y dice qué falta.
2. Probar conexión.
3. Probar catálogo: dice cuántos resultados llegaron, cuántos son válidos, si hay más páginas y qué campos del mapeo se encontraron.
4. Probar reproducción: el servidor obtiene el enlace de una película o un episodio y comprueba que responde. También avisa si es NO COMPATIBLE.
5. Activar: exige lo mínimo para importar y dice qué falta.
6. Iniciar importación (completa) o Sincronizar cambios (solo lo nuevo, si se configuró "cambios desde").
7. Pausar, Reanudar, Reiniciar, o "Reiniciar y confirmar bajas" (para dar de baja títulos que la fuente realmente quitó).
8. Ver errores.

Estados de la importación:
- Completada.
- Completada con advertencias.
- PARCIAL (no completa): se cortó por un límite o un fin de lista dudoso; no se da de baja nada.
- FALLIDA: muestra la causa.
- Pendiente, En curso, En espera (la fuente pidió esperar) o Pausada.
